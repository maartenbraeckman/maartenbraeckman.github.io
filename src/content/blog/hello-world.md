Welcome to my little corner of the internet! 👋

I tried building this site with plain HTML and CSS first, but copy-pasting the same
header onto every page got old fast. So now I'm using **Astro**: I still write HTML,
CSS and TypeScript, but in reusable pieces.

## What you'll find here

- Things I'm building
- Notes on what I'm learning
- Probably a lot about Japan and fennec foxes 🦊

To write a new post, I just add a Markdown file to `src/content/blog/`. That's it!
